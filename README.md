# Weatherly — Weather App

A responsive weather dashboard built with HTML, CSS, and vanilla JavaScript.

## Features
- Live current conditions, five-day forecast, and hourly outlook
- City search powered by Open-Meteo Geocoding API
- Current-location lookup (browser permission required)
- Celsius/Fahrenheit display toggle
- Light/dark theme toggle
- Popular Egyptian city shortcuts
- Responsive mobile, tablet, and desktop layouts
- Weather icons and descriptions mapped from WMO weather codes

## Run it
Open `index.html` in a browser. If your browser blocks API requests from local files, run the folder with a local development server (for example, VS Code Live Server).

## API
Uses Open-Meteo Forecast API and Geocoding API. No API key is required for this demo. See https://open-meteo.com/ for API details and usage terms.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layouts
- `script.js` — API requests, rendering, search, theme and unit toggles
- `assets/weather-app-preview.png` — generated design reference
